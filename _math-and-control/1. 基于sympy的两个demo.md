## 📌 概念勘误与术语说明
在学术与工程应用中，表述需要严谨：
1. **求不定积分（原函数）**：对应俗称的“求积分表达式”。定积分求出的是具体的数值，而**不定积分**求出的是包含变量的解析表达式（原函数）。
2. **求导数（导函数）**：对应俗称的“求微分表达式”。**导数**（Derivative，如 $2x$）表示变化率或斜率；而**微分**（Differential，如 $2x\,dx$）表示函数值的线性增量。算法推导中绝大多数情况求的是**导数**。

## 📝 Demo 1：求不定积分（原函数）

**目标**：输入原函数 $f(x) = x^2$，推导其不定积分表达式 $\int x^2 dx = \frac{x^3}{3} + C$

  

Python

```python
import sympy as sp

# 1. 声明符号变量 (相当于 MATLAB 的 syms x)
x = sp.symbols('x')

# 2. 定义目标函数
f = x**2

# 3. 计算不定积分表达式
# 核心语法: sp.integrate(目标函数, 积分变量)
integral_expr = sp.integrate(f, x)

print("--- 求不定积分 ---")
print("原始函数 f(x):", f)
print("积分表达式 F(x):", integral_expr)
# 终端输出: x**3/3
# 注：SymPy 求不定积分默认省略了常数 C
```

## 📝 Demo 2：求导数（导函数）

**目标**：输入原函数 $f(x) = x^2$，推导其一阶导数表达式 $f'(x) = 2x$

Python

```python
import sympy as sp

# 1. 声明符号变量
x = sp.symbols('x')

# 2. 定义目标函数
f = x**2

# 3. 计算导数表达式
# 核心语法: sp.diff(目标函数, 求导变量)
derivative_expr = sp.diff(f, x)

print("--- 求导数 ---")
print("原始函数 f(x):", f)
print("导数表达式 f'(x):", derivative_expr)
# 终端输出: 2*x
```
