以下是经过严格推导与二次验证的标准永磁直流马达（PMDC）控制模型。模型基于理想化假设（磁路不饱和、忽略电枢反应、无外部负载扰动 $T_L=0$），以端电压 $V(t)$ 为系统唯一输入。

  

### 1. 系统参数说明（国际单位制 SI）

所有公式均基于以下物理参数构建：

  

|**符号**|**参数名称**|**物理意义与说明**|**单位**|
|---|---|---|---|
|$V(t), V(s)$|电枢电压 (Armature Voltage)|系统的输入控制量|伏特 (V)|
|$i(t), I(s)$|电枢电流 (Armature Current)|流过电机线圈的电流|安培 (A)|
|$R$|电枢电阻 (Armature Resistance)|电机线圈的等效电阻|欧姆 ($\Omega$)|
|$L$|电枢电感 (Armature Inductance)|电机线圈的等效电感|亨利 (H)|
|$e(t), E(s)$|反电动势 (Back EMF)|转子切割磁感线产生的对抗电压|伏特 (V)|
|$K_e$|反电动势常数 (Back EMF Constant)|速度与反电动势的比例系数|V/(rad/s)|
|$K_t$|力矩常数 (Torque Constant)|电流与输出电磁力矩的比例系数|N·m/A|
|$T_m(t), T_m(s)$|电磁力矩 (Electromagnetic Torque)|电机产生的驱动扭矩|牛·米 (N·m)|
|$J$|总转动惯量 (Moment of Inertia)|电机转子与折算到电机轴上负载的惯量之和|kg·m²|
|$B$|粘性摩擦系数 (Viscous Friction)|阻碍转动的线性摩擦力矩系数|N·m/(rad/s)|
|$\omega(t), \omega(s)$|角速度 (Angular Velocity)|电机轴的旋转速度|rad/s|
|$\theta(t), \Theta(s)$|角位置 (Angular Position)|电机轴的旋转角度|rad (弧度)|

> **注**：在严格的国际单位制（SI）下，通过能量守恒定律可证，力矩常数与反电动势常数在数值上是相等的，即 **$K_t = K_e$**。为保证公式的物理溯源清晰，下文推导中仍将两者独立区分。
> 
>   

### 2. 基础物理方程

整个直流马达模型由电气子系统与机械子系统耦合而成：

  

**电气子系统（基尔霍夫电压定律 KVL）：** 电枢两端的电压等于电阻压降、电感压降与反电动势之和。

  

$$V(t) = R \cdot i(t) + L \cdot \frac{di(t)}{dt} + e(t)$$

其中反电动势与转速成正比：

  

$$e(t) = K_e \cdot \omega(t)$$

**机械子系统（牛顿第二定律）：** 电机产生的电磁力矩用于克服惯性加速和粘性摩擦。

  

$$T_m(t) = J \cdot \frac{d\omega(t)}{dt} + B \cdot \omega(t)$$

其中电磁力矩与电枢电流成正比：

  

$$T_m(t) = K_t \cdot i(t)$$

**运动学关系：** 速度是位置的导数。

  

$$\omega(t) = \frac{d\theta(t)}{dt}$$

### 3. 输入-输出微分方程 (Time Domain)

将上述基础方程联立，消去中间变量 $i(t)$ 和 $e(t)$，可得到直接描述输入电压 $V(t)$ 与单一输出（速度、位置、力矩）之间的常系数线性微分方程。

  

**电压 $\rightarrow$ 速度输出 $\omega(t)$ 的微分方程：**

  

$$LJ \frac{d^2\omega(t)}{dt^2} + (LB + RJ) \frac{d\omega(t)}{dt} + (RB + K_t K_e) \omega(t) = K_t V(t)$$

**电压 $\rightarrow$ 位置输出 $\theta(t)$ 的微分方程：**

  

$$LJ \frac{d^3\theta(t)}{dt^3} + (LB + RJ) \frac{d^2\theta(t)}{dt^2} + (RB + K_t K_e) \frac{d\theta(t)}{dt} = K_t V(t)$$

**电压 $\rightarrow$ 力矩输出 $T_m(t)$ 的微分方程：**

  

$$LJ \frac{d^2 T_m(t)}{dt^2} + (LB + RJ) \frac{d T_m(t)}{dt} + (RB + K_t K_e) T_m(t) = K_t J \frac{dV(t)}{dt} + K_t B V(t)$$

_(注：力矩的响应与输入电压的导数 $\frac{dV(t)}{dt}$ 相关，这是因为电感的电流不能突变，力矩的瞬态响应受到限制)_

  

### 4. 拉普拉斯变换与传递函数 (s-Domain)

假设系统初始状态为零（$i(0)=0, \omega(0)=0, \theta(0)=0$），对基础方程进行拉氏变换：

  

1. 电气方程：$V(s) = (Ls + R)I(s) + K_e \omega(s)$
    
      
    
2. 机械方程：$K_t I(s) = (Js + B)\omega(s)$
    
      
    
3. 积分关系：$\omega(s) = s \Theta(s)$
    
      
    

通过代数消元，可推导出以下三个标准传递函数：

  

#### 4.1 速度/电压 传递函数 $G_\omega(s)$

将 $I(s) = \frac{(Js + B)}{K_t} \omega(s)$ 代入电气方程，整理得到：

  

$$G_\omega(s) = \frac{\omega(s)}{V(s)} = \frac{K_t}{(Ls + R)(Js + B) + K_t K_e}$$

展开分母：

  

$$G_\omega(s) = \frac{K_t}{L J s^2 + (LB + RJ)s + (RB + K_t K_e)}$$

_（这是一个典型的二阶惯性系统，在伺服控制中用于速度环的设计。）_

  

#### 4.2 位置/电压 传递函数 $G_\theta(s)$

由于位置是速度的积分 $\Theta(s) = \frac{1}{s}\omega(s)$，直接在速度传递函数上增加一个积分环节：

  

$$G_\theta(s) = \frac{\Theta(s)}{V(s)} = \frac{K_t}{s[(Ls + R)(Js + B) + K_t K_e]}$$

$$G_\theta(s) = \frac{K_t}{L J s^3 + (LB + RJ)s^2 + (RB + K_t K_e)s}$$

_（这是一个三阶系统，包含一个原点极点，体现了位置伺服系统的积分特性。）_

  

#### 4.3 力矩/电压 传递函数 $G_T(s)$

已知 $T_m(s) = K_t I(s)$，将 $I(s)$ 从电气方程中解出 $I(s) = \frac{V(s) - K_e \omega(s)}{Ls + R}$，并将速度表达为力矩的函数 $\omega(s) = \frac{T_m(s)}{Js + B}$，代入整理后得到：

  

$$G_T(s) = \frac{T_m(s)}{V(s)} = \frac{K_t(Js + B)}{(Ls + R)(Js + B) + K_t K_e}$$

展开分母：

  

$$G_T(s) = \frac{K_t J s + K_t B}{L J s^2 + (LB + RJ)s + (RB + K_t K_e)}$$

_（分子中的 $s$ 项验证了前文微分方程中电压导数 $\frac{dV}{dt}$ 的存在，在高频状态下（$s \to \infty$），由于电感 $L$ 的作用，力矩无法突变。）_
