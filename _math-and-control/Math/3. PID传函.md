>==🔴输入为误差，传函即为误差的系数的组合，因为拉氏变换的法则，积分倒数/微分倍数，所以可方便求传函。==

理想连续时间 PID 控制器的时域表达式为：

  

$$u(t) = K_p e(t) + K_i \int_{0}^{t} e(\tau)\,d\tau + K_d \frac{de(t)}{dt}$$

其中：

  

- $e(t)$ 是误差信号（设定值与实际反馈之差），在 $s$ 域记为 $E(s) = \mathcal{L}\{e(t)\}$；
    
- $u(t)$ 是控制器输出，在 $s$ 域记为 $U(s) = \mathcal{L}\{u(t)\}$；
    
- $K_p$、$K_i$、$K_d$ 分别为比例、积分、微分增益。
    

### 1. 逐项做拉氏变换（零初始条件 $e(0^-) = 0$ 时）

利用拉氏变换的线性性以及积分、微分性质：

  

- **比例项 $K_p e(t)$**：
    
    $$\mathcal{L}\{K_p e(t)\} = K_p E(s)$$
    
- **积分项 $K_i \int_{0}^{t} e(\tau)\,d\tau$**：
    
    $$\mathcal{L}\left\{K_i \int_{0}^{t} e(\tau)\,d\tau\right\} = \frac{K_i}{s} E(s)$$
    
- **微分项 $K_d \frac{de(t)}{dt}$**（假设零初始条件 $e(0^-) = 0$）：
    
    $$\mathcal{L}\left\{K_d \frac{de(t)}{dt}\right\} = K_d s E(s)$$
    

把三项相加得到输出拉氏变换：

  

$$U(s) = \left( K_p + \frac{K_i}{s} + K_d s \right) E(s)$$

### 2. 传递函数形式 $G_{\text{PID}}(s) = \frac{U(s)}{E(s)}$

#### 并行 / 标准增益形式

$$G_{\text{PID}}(s) = K_p + \frac{K_i}{s} + K_d s$$

通分后也可写成有理分式（带一个零点或两个零点）：

  

$$G_{\text{PID}}(s) = \frac{K_d s^2 + K_p s + K_i}{s}$$

#### 工程常用时间常数形式（$T_i$ 积分时间，$T_d$ 微分时间）

令 $K_i = \frac{K_p}{T_i}$、$K_d = K_p T_d$，则：

$$G_{\text{PID}}(s) = K_p \left( 1 + \frac{1}{T_i s} + T_d s \right) = K_p \frac{T_i T_d s^2 + T_i s + 1}{T_i s}$$

### 3. 工程实现时的关键补充

1. **纯微分 $K_d s$ 高频噪声放大**：理想微分项 $s$ 的幅频特性随频率线性上升（$+20\text{ dB/dec}$），实际工程中通常会给微分项加一个一阶低通滤波极点（即**实际微分 / 滤波 PID**）：
    
    $$G_d(s) = \frac{K_d s}{\tau_f s + 1} \quad \text{或} \quad \frac{K_p T_d s}{\frac{T_d}{N} s + 1}$$
    
    其中 $\tau_f$ 或 $T_d/N$ 对应高频衰减时间常数。
    
2. **非零初值**：若 $e(0^-) \neq 0$，微分项变换需补上 $-K_d e(0^-)$，不能直接只乘 $s$。
