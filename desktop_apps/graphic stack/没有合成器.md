#### 2. 没有合成器，GUI 就不可用了吗？

**绝对不是！GUI 完全可用，而且性能更高、延迟更低。**

- **合成器（Compositor）的职责**：主要用于**多窗口桌面管理**（如 Windows / Ubuntu 桌面，处理多个独立窗口的拖拽、重叠、缩放和图层混合）。
    
- **EGLFS（无合成器模式）**：专为嵌入式单应用全屏独占（Single-App Fullscreen）设计（如车载中控屏、工控机界面、医疗仪表、POS机）。
    
    - **优点**：不需要 Wayland Compositor 在中间做二次内存拷贝与合成，Qt 应用程序直接把渲染结果送给 DRM 驱动扫出，**显著节省 CPU/GPU 算力和 RAM 占用，大幅降低渲染延迟**。
        
    - **局限**：同一时刻屏幕上只能运行并独占显示一个 Qt 主程序（如果需要多个应用画面，必须在 Qt 内部自己做多视图管理）。
