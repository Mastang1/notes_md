## Reference policy

- A tutorial must never say only “see the manual”. It must name the manual and give a chapter/section or at least a searchable keyword.
- Page numbers are included only when verified for the exact version. Where page numbers are not verified, the tutorial explicitly gives chapter/section and `Ctrl+F` keywords.
- For Linux/Zephyr mechanisms, official kernel/Zephyr docs take precedence over vendor tutorial wording.
