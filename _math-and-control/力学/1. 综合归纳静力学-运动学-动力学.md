# 工程力学：静力学 / 运动学 / 动力学 划分笔记

## 一、 核心分界一句话总览

- **静力学**：看**力系平衡**（力、力矩、力偶矩、摩擦与约束反力），不看运动演化，也不用质量 $m$、转动惯量 $J$。
    
- **运动学**：看**几何与运动关系**（各点的位置、轨迹、线/角速度、线/角加速度及约束关联），只管“怎么动”，不问“为什么动”，也不用 $m$ 和 $J$。
    
- **动力学**：把**力/力矩**与运动变化（加速度/角加速度、动能/动量）**通过**惯性属性（$m$、$J$）联系起来，回答“为什么会这样动”。
    

> **退化与串联关系**：实际机构分析常先用**运动学**找各点/各构件运动关系，再用**动力学**结合 $m$、$J$ 与受力列方程；若加速度为零，动力学方程退化为**静力学**平衡方程。

## 二、 三大模块细化归纳

### 1. 静力学（Statics）—— 力系平衡与等效

- **关注重点**：平衡条件下的合力与合力矩、力偶矩、静摩擦/滚动摩阻约束、支座/铰链反力。
    
- **物理属性特征**：**不涉及**质量 $m$、转动惯量 $J$ 与加速度。
    
- **代表公式**：
    
    - 平面力系平衡：
        
        $$\sum F_x = 0, \qquad \sum F_y = 0, \qquad \sum M_O(\mathbf{F}) = 0$$
        
    - 力偶矩与力向一点平移：
        
        $$M = \pm F d, \qquad \mathbf{M}_O = \mathbf{r} \times \mathbf{F}$$
        
    - 静摩擦约束：
        
        $$F_f \le f_s N, \qquad F_{\max} = f_s N$$
        
- **记忆锚点**：合力为 $\mathbf{0}$ 且合力矩为 $\mathbf{0}$ 的平衡状态（包含静止与匀速直线/匀速定轴转动）。
    

### 2. 运动学（Kinematics）—— 各点运动与几何约束

- **关注重点**：刚体平动、定轴转动、平面运动等过程中，各点位置、速度、加速度的几何与微分/积分关系。
    
- **物理属性特征**：只涉几何位矢、角度及对时间的导数（$\mathbf{r}, \mathbf{v}, \mathbf{a}, \theta, \omega, \alpha$）；**不涉及**力、力矩、质量 $m$、转动惯量 $J$。
    
- **代表公式**：
    
    - 定轴转动点与线量关系：
        
        $$v_t = \omega r, \qquad a_n = \omega^2 r, \qquad a_t = \alpha r$$
        
    - 平面运动速度/加速度基点法：
        
        $$\mathbf{v}_B = \mathbf{v}_A + \boldsymbol{\omega} \times \mathbf{r}_{BA}$$
        
        $$\mathbf{a}_B = \mathbf{a}_A + \boldsymbol{\alpha} \times \mathbf{r}_{BA} - \omega^2 \mathbf{r}_{BA}$$
        
- **记忆锚点**：纯“几何 + 时间导数”的运动账本，不问施力与惯性。
    

### 3. 动力学（Dynamics）—— 惯性、力与运动演化的耦合

- **关注重点**：外力/力矩如何驱动刚体产生加速度 $\mathbf{a}$、角加速度 $\alpha$，以及功、能、动量、动量矩的转化与守恒。
    
- **物理属性特征**：**必须引入**刚体惯性参数——质量 $m$ 与转动惯量 $J$。
    
- **代表公式**：
    
    - 牛顿-欧拉平面运动方程：
        
        $$\sum \mathbf{F}_{\text{ext}} = m\mathbf{a}_C, \qquad \sum M_C(\mathbf{F}_{\text{ext}}) = J_C\alpha$$
        
    - 刚体动能与动能定理：
        
        $$T = \frac{1}{2}mv_C^2 + \frac{1}{2}J_C\omega^2, \qquad \Delta T = W_{\text{ext}} + W_{\text{int}}$$
        
- **记忆锚点**：看到 $m$、$J$ 与 $\mathbf{a}$、$\alpha$、动能 $T$ 同台出现，就是动力学。
    

## 三、 横向对照表

|**划分维度**|**静力学**|**运动学**|**动力学**|
|---|---|---|---|
|**核心研究对象**|平衡力系、力矩/力偶、约束反力|刚体及各点位矢、线/角速度与加速度|受力与惯性共同决定的加速度、动能、动量|
|**惯性参数（$m, J$）**|不用|不用|**核心参数**|
|**是否包含加速度**|平衡态下加速度为 $\mathbf{0}$|包含（几何与运动学关系）|**包含**（由力与惯性决定）|
|**典型方程**|$\sum F_x=0,\ \sum F_y=0,\ \sum M_O=0$|$\mathbf{v}_B=\mathbf{v}_A+\boldsymbol{\omega}\times\mathbf{r}_{BA}$|$m\mathbf{a}_C=\sum\mathbf{F},\ J_C\alpha=\sum M_C,\ \Delta T=W$|
