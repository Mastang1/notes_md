根据提供的知识库，针对在嵌入式下位机（如采用 Yocto 构建的 Hailo-8 系统）上的库组成、分层结构以及从零开始的应用开发方案，整理如下：

---

### 一、 下位机库与组件结构（分类与分层）

通过 `meta-hailo` 构建后，部署在下位机目标文件系统中的组件分为以下层级：

#### 1. 硬件驱动与固件层（Driver & Firmware）

该层直接管理硬件接口与底层交互，主要由 `meta-hailo-accelerator` 提供：

- **`hailo-firmware`**：
    - 安装路径：`/lib/firmware/hailo/hailo8_fw.bin` [[Yocto](https://hailo.ai/developer-zone/documentation/hailort-v4-23-0/?sp_referrer=yocto%2Fyocto.html)]。
    - 作用：Hailo-8 芯片运行所需的底层固件 [[Yocto](https://hailo.ai/developer-zone/documentation/hailort-v4-23-0/?sp_referrer=yocto%2Fyocto.html)]。
- **`hailo-pci` (Hailo PCIe Driver)**：
    - 作用：Hailo-8 的 PCIe 内核驱动程序，负责系统识别芯片、DMA 传输及中断通信 [[Yocto](https://hailo.ai/developer-zone/documentation/hailort-v4-23-0/?sp_referrer=yocto%2Fyocto.html)]。

#### 2. 运行时核心层（HailoRT Runtime）

位于用户空间，直接与驱动交互，提供模型加载与推理执行功能，主要由 `meta-hailo-libhailort` 提供：

- **`libhailort`**：
    - 安装路径：动态库安装至系统的标准库/二进制目录（如 `/usr/bin`、`/usr/lib`）[[Yocto](https://hailo.ai/developer-zone/documentation/hailort-v4-23-0/?sp_referrer=yocto%2Fyocto.html)]。
    - 作用：HailoRT C/C++ 核心 API 共享库，负责操作 VDevice/Device、读取解析 HEF 模型、流控制（Streams/VStreams）以及调度 [[Code structure](https://hailo.ai/developer-zone/documentation/hailort-v4-23-0/?sp_referrer=tutorials%2Fcpp_tutorial.html#code-structure); [Yocto](https://hailo.ai/developer-zone/documentation/hailort-v4-23-0/?sp_referrer=yocto%2Fyocto.html)]。
- **`hailortcli`**：
    - 安装路径：`/usr/bin/hailortcli` [[Yocto](https://hailo.ai/developer-zone/documentation/hailort-v4-23-0/?sp_referrer=yocto%2Fyocto.html)]。
    - 作用：命令行工具，用于推理验证、芯片固件控制与状态测量 [[Yocto](https://hailo.ai/developer-zone/documentation/hailort-v4-23-0/?sp_referrer=yocto%2Fyocto.html)]。
- **`pyhailort`**：
    - 安装路径：`/usr/lib/python*/site-packages/` [[Yocto](https://hailo.ai/developer-zone/documentation/hailort-v4-23-0/?sp_referrer=yocto%2Fyocto.html)]。
    - 作用：HailoRT 的 Python API 封装 [[Yocto](https://hailo.ai/developer-zone/documentation/hailort-v4-23-0/?sp_referrer=yocto%2Fyocto.html)]。

#### 3. 管道与多媒体中间件层（GStreamer & TAPPAS）

在运行时库之上构建音视频流水线和后处理，由 `meta-hailo-libhailort` 和 `meta-hailo-tappas` 提供：

- **`libgsthailo`**：
    - 安装路径：`/usr/lib/gstreamer-1.0/libgsthailo.so` [[Yocto](https://hailo.ai/developer-zone/documentation/hailort-v4-23-0/?sp_referrer=yocto%2Fyocto.html)]。
    - 作用：Hailo 核心 GStreamer 插件（依赖 `libhailort`），用于在多媒体管道中直接接入硬件推理 [[Yocto](https://hailo.ai/developer-zone/documentation/hailort-v4-23-0/?sp_referrer=yocto%2Fyocto.html)]。
- **`libgsthailotools`**：
    - 作用：TAPPAS 扩展 GStreamer 插件库（如 `hailofilter` 等）[[Forum Post: Tappas on Redhat](https://community.hailo.ai/t/2843); [Example](https://hailo.ai/developer-zone/documentation/tappas_5.1.0_user_guide.pdf)]。
- **`hailo-post-processes` (后处理库)**：
    - 包含常见视觉任务后处理动态库（例如 `libyolo_post.so`、`libmobilenet_ssd_post.so`、`libclassification.so`、`libdetection_draw.so` 等）[[Example](https://hailo.ai/developer-zone/documentation/tappas_5.1.0_user_guide.pdf)]。
- **`tappas-tracers`**：
    - 用于流水线分析和调试的性能追踪工具（如分析 CPU 使用率与流水线延迟）[[TAPPAS](https://hailo.ai/developer-zone/documentation/tappas_5.1.0_user_guide.pdf); [Forum Post: Tappas GstShark negative CPU values](https://community.hailo.ai/t/16310)]。

### 二、 从零开始的应用开发方案

在已部署上述库的下位机上，开发应用主要分为**直接使用 HailoRT C++ API** 或 **使用 GStreamer 多媒体管道**两种模式。

#### 方案 A：基于 HailoRT C++ API 开发（适合轻量级、自定义数据源）

如果不依赖复杂的视频解码管线，可直接调用 HailoRT API 处理数据：

1. **设备初始化与虚拟化（VDevice）**
    - 使用 `hailort::VDevice::create()` 创建虚拟设备 [[Code structure](https://hailo.ai/developer-zone/documentation/hailort-v4-23-0/?sp_referrer=tutorials%2Fcpp_tutorial.html#code-structure)]。
    - 默认参数下会自动启用模型调度器（Model Scheduler，Round Robin 调度），无需手动在应用中频繁激活和停用网络组 [[Code structure](https://hailo.ai/developer-zone/documentation/hailort-v4-23-0/?sp_referrer=tutorials%2Fcpp_tutorial.html#code-structure)]。
2. **加载 HEF 并配置**
    - 调用 `hailort::Hef::create("model.hef")` 读取编译好的模型文件 [[Code structure](https://hailo.ai/developer-zone/documentation/hailort-v4-23-0/?sp_referrer=tutorials%2Fcpp_tutorial.html#code-structure)]。
    - 使用 `Hef::create_configure_params()` 生成配置参数，并调用 `VDevice::configure()` 获取 `ConfiguredNetworkGroupVector` [[Code structure](https://hailo.ai/developer-zone/documentation/hailort-v4-23-0/?sp_referrer=tutorials%2Fcpp_tutorial.html#code-structure)]。
3. **创建虚拟流（VStreams）**
    - 分别调用 `NetworkGroup::make_input_vstream_params()` 与 `make_output_vstream_params()` [[Code structure](https://hailo.ai/developer-zone/documentation/hailort-v4-23-0/?sp_referrer=tutorials%2Fcpp_tutorial.html#code-structure); [Code structure](https://hailo.ai/developer-zone/documentation/hailort-v4-23-0/?sp_referrer=tutorials%2Fcpp_tutorial.html#id18)]。
    - 通过 `hailort::VStreamsBuilder::create_input_vstreams()` 和 `create_output_vstreams()` 实例化虚拟输入/输出流 [[Code structure](https://hailo.ai/developer-zone/documentation/hailort-v4-23-0/?sp_referrer=tutorials%2Fcpp_tutorial.html#code-structure)]。
4. **多线程并发读写与推理**
    - 输入线程：负责将图像数据传入输入流 [[Code structure](https://hailo.ai/developer-zone/documentation/hailort-v4-23-0/?sp_referrer=tutorials%2Fcpp_tutorial.html#code-structure)]。
    - 输出线程：调用 `hailort::OutputVStream::read()` 接收并解析模型推理结果 [[Code structure](https://hailo.ai/developer-zone/documentation/hailort-v4-23-0/?sp_referrer=tutorials%2Fcpp_tutorial.html#code-structure)]。

#### 方案 B：基于 GStreamer / TAPPAS 插件开发（适合视频流端到端处理）

如果需要接入摄像头或 RTSP 并进行实时画框与显示：

1. **选择视频源与预处理**
    - 采用标准 GStreamer 插件（如 `v4l2src`、`videoscale`、`videoconvert`）将输入格式缩放转换至模型输入分辨率与格式 [[Forum Post: Tappas GstShark negative CPU values](https://community.hailo.ai/t/16310)]。
2. **接入 Hailo 推理与后处理插件**
    - 串联 `libgsthailo` 与 `libgsthailotools` 提供的插件元素 [[Forum Post: Tappas on Redhat](https://community.hailo.ai/t/2843); [Yocto](https://hailo.ai/developer-zone/documentation/hailort-v4-23-0/?sp_referrer=yocto%2Fyocto.html)]。
    - 通过加载后处理动态库（例如 `libyolo_post.so`），自动在管道内部解析 NMS 框并转换为 GStreamer metadata [[Example](https://hailo.ai/developer-zone/documentation/tappas_5.1.0_user_guide.pdf)]。
3. **输出与调试**
    - 输出到显示单元（如 `ximagesink`）或网络输出 [[Forum Post: Tappas GstShark negative CPU values](https://community.hailo.ai/t/16310)]。
    - 性能排查时，可通过环境变量配置 tracers 进行分析（例如仅开启 `cpuusage` 避免与 `threadmonitor` 冲突导致的数据异常）[[Forum Post: Tappas GstShark negative CPU values](https://community.hailo.ai/t/16310)]：
        
        ```bash
        export GST_DEBUG="GST_TRACER:7"
        export GST_TRACERS="cpuusage"
        export GST_DEBUG_FILE=/tmp/gst-shark.log
        ```
