# 指数衰减与工程直觉笔记

## 1. 核心定义与参数关系
* 标准指数衰减形式：$f(t) = e^{-t/\tau}$（$t \ge 0$）。
* 衰减率 / 极点位置：若写为 $e^{at}$（如 $e^{-5t}$），则 $a = -5$ 为衰减率，对应一阶系统极点 $s = -5$。
* 时间常数 $\tau$：$\tau = \frac{1}{|a|}$。对于 $e^{-5t}$，$\tau = \frac{1}{5} = 0.2$。
* 乘法递推性质：每经过 $1\tau$，幅值乘以 $e^{-1} \approx 0.3679$（约 $36.8\%$）；经过 $k\tau$，剩余比例为 $e^{-k}$，下降比例为 $1 - e^{-k}$。

## 2. 关键比例与时间倍数对照
| 经过时间 $t$ | 剩余比例 $e^{-k}$ | 下降比例 $1 - e^{-k}$ | 说明 |
| :--- | :--- | :--- | :--- |
| $0.693\tau$ | $50.0\%$ | $50.0\%$ | 半衰期，$\ln(2) \approx 0.693$ |
| $1\tau$ | $\approx 36.8\%$ | $\approx 63.2\%$ | 典型一阶响应时间常数节点 |
| $2\tau$ | $\approx 13.5\%$ | $\approx 86.5\%$ | 衰减已超八成半 |
| $2.303\tau$ | $10.0\%$ | $90.0\%$ | 下降 90% 的精确倍数，$\ln(10) \approx 2.303$ |
| $3\tau$ | $\approx 5.0\%$ | $\approx 95.0\%$ | 剩余约 5% |
| $4\tau$ | $\approx 1.8\%$ | $\approx 98.2\%$ | 剩余不足 2% |
| $4.605\tau$ | $1.0\%$ | $99.0\%$ | 下降 99% 的精确倍数，$\ln(100) \approx 4.605$ |
| $5\tau$ | $\approx 0.67\%$ | $\approx 99.3\%$ | 剩余不足 1% |

## 3. 工程拍脑袋法则
* **$1\tau$**：看“单步衰减”，剩下约 $37\%$，掉了约 $63\%$。
* **$3\tau$**：看“基本完成”，大约衰减 $95\%$，残余约 $5\%$。
* **$5\tau$**：看“彻底收敛 / 稳态”，衰减超 $99\%$，残余不到 $1\%$。
* **反算倍数口诀**：要让剩余比例变成 $p$（如 $0.1$），所需时间倍数为 $-\ln(p) = \ln(1/p)$。
* **带入 $e^{-5t}$（$\tau = 0.2$）**：
  * 下降 $63.2\%$ 约需 $0.2$
  * 下降 $90\%$ 约需 $0.46$
  * 下降 $95\%$（$3\tau$）约需 $0.6$
  * 下降 $99.3\%$（$5\tau$）约需 $1.0$

## 5. $\ln(x)$ 核心运算规则
* **乘除变加减**：
  * $\ln(AB) = \ln(A) + \ln(B)$（$A > 0, B > 0$）
  * $\ln\left(\frac{A}{B}\right) = \ln(A) - \ln(B)$（$A > 0, B > 0$）
* **幂次变乘法**：
  * $\ln(A^k) = k\ln(A)$（$A > 0$，$k$ 为实数）
  * 特别地，开根号：$\ln(\sqrt[n]{A}) = \frac{1}{n}\ln(A)$
* **倒数变负号**：
  * $\ln\left(\frac{1}{A}\right) = -\ln(A)$（求衰减倍数时常用，例如剩余 $1/10$，倍数为 $-\ln(0.1) = \ln(10) \approx 2.303$）
* **特殊值与互逆关系**：
  * $\ln(1) = 0$，$\ln(e) = 1$
  * $\ln(e^u) = u$；当 $u > 0$ 时，$e^{\ln(u)} = u$
* **换底公式**：
  * $\log_b(x) = \frac{\ln(x)}{\ln(b)}$（$x > 0,\ b > 0,\ b \neq 1$）
* **小量近似**（$|x| \ll 1$）：
  * $\ln(1 + x) \approx x$（例如 $\ln(1.01) \approx 0.01$，$\ln(0.99) \approx -0.01$）
