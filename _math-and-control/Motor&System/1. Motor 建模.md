>总结微分方程的原理:
>		1. 电枢内外电压平衡
>		2. 反电动势与电流的比例关系
>		3. 动力学平衡
>		4. 运动学关系（速度积分 = 角度）

## 第一幕：物理建模——把直流有刷电机拆成“两个一阶惯性 + 一个积分器”

不要把电机当成黑盒。打开它的物理外壳，里面只运行着**三条中学/大一物理定律**。我们把每一条写成微分方程，再用拉氏变换（求导变乘以 $s$）把它变成传递函数，你就能亲眼看到你手里这台电机的**全部天生极点**。

### 1. 电气子系统：PWM 电压 $u(t)$ 如何变成电流 $i(t)$？

直流电机的电枢绕组本质上就是一个**电阻 $R$ 串联一个电感 $L$**，再加上转子切割磁感线自己发出来的**反电动势 $e_b(t)$**。

根据基尔霍夫电压定律，你通过 H 桥加在电机两端的平均电压 $u(t)$ 被分成了三份：

$$u(t) = \underbrace{R \cdot i(t)}_{\text{电阻发热压降}} + \underbrace{L \frac{di(t)}{dt}}_{\text{电感抗拒电流变化}} + \underbrace{e_b(t)}_{\text{反电动势}}$$

其中反电动势与转速 $\omega(t)$ 成正比：$e_b(t) = K_e \cdot \omega(t)$（$K_e$ 为反电动势系数）。

两边做拉氏变换（$\frac{d}{dt} \to s$）：

$$U(s) - K_e \Omega(s) = (Ls + R) I(s)$$

移项得到**电气环节的传递函数 $G_{elec}(s)$**：

$$G_{elec}(s) = \frac{I(s)}{U(s) - E_b(s)} = \frac{1}{Ls + R} = \frac{1/R}{\tau_e s + 1}$$

- **暴露出第 1 颗极点（电气极点）**：$p_{elec} = -\frac{R}{L} = -\frac{1}{\tau_e}$。
    
- **物理脾气**：直流有刷电机的电感 $L$ 通常很小（零点几毫亨到几毫亨），所以电气时间常数 $\tau_e = \frac{L}{R}$ 极短（通常只有 **$0.2\text{ms} \sim 3\text{ms}$**）。这颗极点离虚轴非常远，**反应极快**！
    

### 2. 机电能量桥梁：电流 $i(t)$ 直接变成电磁力矩 $\tau_m(t)$

通电导线在磁场中受安培力，产生的电磁转矩严格正比于电枢电流：

$$\tau_m(t) = K_t \cdot i(t)$$

- **核心工程结论**：$K_t$ 是个纯比例常数（没有 $s$，没有惯性延迟）。也就是说，**控制住了电流 $i(t)$，就等价于 100% 瞬时控制住了电机的输出力矩！** 这也是“电流环”又叫“力矩环”的根本原因。（注：在国际单位制下，力矩系数 $K_t$ [$\text{N}\cdot\text{m/A}$] 与反电动势系数 $K_e$ [$\text{V}\cdot\text{s/rad}$] 数值严格相等）。
    

### 3. 机械子系统：电磁力矩 $\tau_m(t)$ 如何变成角速度 $\omega(t)$？

转子（连同减速箱、联轴器和负载）是一个带转动惯量 $J$ 和粘滞摩擦阻尼 $B$ 的旋转刚体。根据牛顿第二旋转定律：

$$J \frac{d\omega(t)}{dt} + B \omega(t) = \tau_m(t) - \tau_L(t)$$

（其中 $\tau_L(t)$ 是外部未知负载力矩与干摩擦阻力）。

先看电机本体（令外负载 $\tau_L = 0$），两边做拉氏变换：

$$(Js + B)\Omega(s) = T_m(s)$$

得到**机械环节的传递函数 $G_{mech}(s)$**：

$$G_{mech}(s) = \frac{\Omega(s)}{T_m(s)} = \frac{1}{Js + B} = \frac{1/B}{\tau_m s + 1}$$

- **暴露出第 2 颗极点（机械极点）**：$p_{mech} = -\frac{B}{J} = -\frac{1}{\tau_m}$。
    
- **物理脾气**：机械有惯性，转起来慢、停下来也慢。机械时间常数 $\tau_m = \frac{J}{B}$ 通常在 **$20\text{ms} \sim 300\text{ms}$** 之间，**比电气极点慢 10 倍到 100 倍！**
    

### 4. 运动学环节：角速度 $\omega(t)$ 如何变成角度 $\theta(t)$？

角度就是角速度对时间的累加（积分）：

$$\theta(t) = \int_0^t \omega(\tau) d\tau \xrightarrow{\text{拉氏变换}} G_{pos}(s) = \frac{\Theta(s)}{\Omega(s)} = \frac{1}{s}$$

- **暴露出第 3 颗极点（原点纯积分极点）**：$p_{pos} = 0$。它直接骑在复平面的原点上。
    

### 5. 全貌汇总：你的电机到底长什么样？

把上面四步串起来，你的直流有刷电机在 $s$ 域里是一条极其清晰的因果链：

$$\text{电压 } U(s) \xrightarrow[-E_b(s)]{\frac{1}{Ls+R}} \text{电流 } I(s) \xrightarrow{\times K_t} \text{力矩 } T_m(s) \xrightarrow[-\tau_L(s)]{\frac{1}{Js+B}} \text{角速度 } \Omega(s) \xrightarrow{\frac{1}{s}} \text{角度 } \Theta(s)$$

如果强行把它们合并成一个“电压直接到角度”的总传递函数，它会变成一个**三阶系统**：

$$G_{all}(s) = \frac{\Theta(s)}{U(s)} = \frac{K_t}{s \left[ (Ls + R)(Js + B) + K_e K_t \right]}$$

记住这个公式，它是你后面理解“为什么非要搞三环串级”的唯一钥匙。
