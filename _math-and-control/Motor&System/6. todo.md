# PID 微分先行（测量值微分 + 负号阻尼）笔记

## 1. 核心原理
标准位置式 PID 对误差 $e(k) = r(k) - y(k)$ 求导：
$$u_d(t) = K_d \frac{de(t)}{dt} = K_d \frac{dr(t)}{dt} - K_d \frac{dy(t)}{dt}$$

**微分先行（Derivative on Measurement）**将“给定值变化率项”去掉，仅保留测量值 $y(t)$ 变化率的负项作为阻尼项：
$$u_d(t) = -K_d \frac{dy(t)}{dt}$$

离散化（采样周期 $T_s$）常见写法：
$$\Delta y_{\text{rate}}(k) = \frac{y(k) - y(k-1)}{T_s}$$
$$u_d(k) = -K_d \cdot \Delta y_{\text{rate}}(k)$$

### 为什么是“取负数”？
* 设控制输出 $u$ 与测量值 $y$ 为正相关（$u$ 增大，$y$ 倾向于增大）。
* 当被控量快速上升时，$\frac{dy}{dt} > 0$，取负后 $u_d = -K_d \frac{dy}{dt} < 0$，相当于对控制输出施加**反向制动力 / 粘滞阻尼**，提前抑制冲过头（超调）。
* 当被控量快速下降时，$\frac{dy}{dt} < 0$，取负后 $u_d > 0$，相当于提供**正向托举 / 缓冲力**，减缓下落或回落速度。
* 设定值 $r(k)$ 发生阶跃跳变时，由于 $y(k)$ 不会瞬间突变，$u_d(k)$ 不会产生由“给定跳变”引发的微分尖峰。

---

## 2. 优势与劣势

### 优势
1. **消除设定值阶跃引起的微分尖峰**：给定值频繁切换或阶跃变化时，不会瞬间把控制量顶满或打穿限幅。
2. **阻尼作用纯粹且直观**：本质上相当于引入了与被控量变化率成正比的阻尼项（类似机械系统的阻尼器），有助于减小超调、抑制振荡。
3. **易于与前馈解耦**：需要加快给定响应时，可通过**速度/加速度前馈**或**给定轨迹规划（如 S 曲线、梯形规划）**单独设计，不与阻尼项耦合。
4. **对外部扰动依然有效**：当外部负载变化导致 $y(t)$ 加快变化时，依然能感知变化率并产生抑制作用。

### 劣势
1. **对测量高频噪声敏感**：求差分/导数会放大高频噪声；若 $y(k)$ 含编码器量化抖动或 ADC 噪声，直接微分会导致输出抖动或电机高频啸叫。
2. **对给定阶跃没有“瞬时加速冲量”**：给定突变瞬间没有 $dr/dt$ 推动，若前馈不足，起步响应可能偏柔和。
3. **依赖采样周期 $T_s$ 的稳定性**：若控制周期抖动较大且未用真实 $\Delta t$ 归一化，阻尼系数等效值会波动。

---

## 3. 工程落地要点
* **微分滤波**：实际代码中通常对测量值或微分项加**一阶低通滤波（LPF）**，或结合编码器/观测器得到的平滑速度量。
* **符号与正反作用检查**：确认系统正反作用关系后再确定符号，避免阻尼变“正反馈助推”导致发散。
* **首拍初始化**：首次执行时保存 `prev_meas = meas`，避免 `prev_meas` 为 0 导致第一拍出现虚假变化率。

### C 语言参考片段
```c
typedef struct {
    float kp;
    float ki;
    float kd;
    float d_lpf_alpha;   /* 微分项低通滤波系数 (0, 1] */
    float out_min;
    float out_max;
    float integral;
    float prev_meas;
    float d_filt;
    int   initialized;
} PID_DerivOnMeas;

float pid_step(PID_DerivOnMeas *pid, float setpoint, float meas, float dt) {
    if (dt <= 0.0f) {
        return pid->prev_meas;
    }

    float error = setpoint - meas;

    if (!pid->initialized) {
        pid->prev_meas = meas;
        pid->d_filt = 0.0f;
        pid->initialized = 1;
    }

    float p_term = pid->kp * error;

    /* 测量值变化率 + 低通滤波，取负作为阻尼项 */
    float meas_rate = (meas - pid->prev_meas) / dt;
    pid->d_filt += pid->d_lpf_alpha * (meas_rate - pid->d_filt);
    float d_term = -pid->kd * pid->d_filt;

    /* 积分项与抗饱和（示例为简单限幅） */
    pid->integral += pid->ki * error * dt;
    if (pid->integral > pid->out_max) pid->integral = pid->out_max;
    if (pid->integral < pid->out_min) pid->integral = pid->out_min;

    float out = p_term + pid->integral + d_term;
    if (out > pid->out_max) out = pid->out_max;
    if (out < pid->out_min) out = pid->out_min;

    pid->prev_meas = meas;
    return out;
}
```

## 4. 实际产品中的常见使用场景

1. **伺服与位置/角度控制环**：当位置外环或角度环需要阻尼抑制超调，但上位机位置指令存在阶跃或快速切换时，用测量值微分避免力矩/速度指令突跳。
    
2. **云台、光电吊舱与指向机构**：目标指令经常切换或受扰动时，需要平稳阻尼防止抖动和过冲。
    
3. **带惯量负载的直流/力矩电机控制**：负载转动惯量较大时，利用测量变化率阻尼抑制超调，再配合前馈提升跟踪速度。
    
4. **温度、液位、压力等过程控制仪表**：设定值修改频繁或存在设定阶跃时，工业控制器普遍采用微分先行保证调节平稳。
