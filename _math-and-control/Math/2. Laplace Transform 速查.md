明白，直接看**如何从 $f(t)$ 一步步积分推出 $F(s)$**，把核心推导抓出来最直观。

  

拉普拉斯变换统一定义：

  

$$F(s) = \mathcal{L}\{f(t)\} = \int_{0}^{\infty} f(t)e^{-st}\,dt$$

下面把最基础的几类函数按“**时域 $f(t)$ $\longrightarrow$ 积分推导过程 $\longrightarrow$ 拉氏变换 $F(s)$**”整理成表：

  

### 基础函数从 $f(t)$ 推到 $F(s)$ 对照表

|**函数类型**|**时域 f(t)（t≥0）**|**推导过程核心步骤（设 Re(s) 满足收敛）**|**拉氏变换 F(s)**|
|---|---|---|---|
|**常数**|$C$|$\displaystyle \int_0^\infty C e^{-st}\,dt = C\left[\frac{e^{-st}}{-s}\right]_0^\infty = C\left(0 - \frac{-1}{s}\right)$|$\displaystyle \frac{C}{s}$|
|**单位阶跃**|$1$（即 $\mu(t)$）|常数表中令 $C = 1$|$\displaystyle \frac{1}{s}$|
|**指数衰减**|$e^{-at}$（$a > 0$）|$\displaystyle \int_0^\infty e^{-at}e^{-st}\,dt = \int_0^\infty e^{-(s+a)t}\,dt = \left[\frac{e^{-(s+a)t}}{-(s+a)}\right]_0^\infty$|$\displaystyle \frac{1}{s + a}$|
|**指数增长**|$e^{at}$（$a > 0$）|$\displaystyle \int_0^\infty e^{at}e^{-st}\,dt = \int_0^\infty e^{-(s-a)t}\,dt = \left[\frac{e^{-(s-a)t}}{-(s-a)}\right]_0^\infty$|$\displaystyle \frac{1}{s - a}$|
|**一次幂（斜坡）**|$t$|分部积分 $\int u\,dv = uv - \int v\,du$，令 $u = t,\, dv = e^{-st}dt$：<br><br>  <br>  <br><br>$\displaystyle \left[-\frac{t e^{-st}}{s}\right]_0^\infty + \frac{1}{s}\int_0^\infty e^{-st}\,dt = 0 + \frac{1}{s}\cdot\frac{1}{s}$|$\displaystyle \frac{1}{s^2}$|
|**二次幂**|$t^2$|连续两次分部积分（每次降一次幂、多除一个 $s$）：<br><br>  <br>  <br><br>$\displaystyle \int_0^\infty t^2 e^{-st}\,dt = \frac{2}{s}\int_0^\infty t e^{-st}\,dt = \frac{2}{s}\cdot\frac{1}{s^2}$|$\displaystyle \frac{2!}{s^3} = \frac{2}{s^3}$|
|**$n$ 次幂**|$t^n$（$n \in \mathbb{N}$）|归纳 $n$ 次分部积分，每次降幂出系数 $k$ 并除以 $s$|$\displaystyle \frac{n!}{s^{n+1}}$|
|**指数 $\times$ 幂**|$t e^{-at}$|先把 $e^{-at}$ 和 $e^{-st}$ 合并成 $e^{-(s+a)t}$，再对 $t$ 做一次分部积分（相当于把 $t$ 的结果 $\frac{1}{s^2}$ 里的 $s$ 换成 $s+a$）|$\displaystyle \frac{1}{(s + a)^2}$|

### 一眼看穿推导套路

1. **常数 / 指数**：直接把 $e^{kt}$ 和 $e^{-st}$ 合并成 $e^{-(s-k)t}$，积分后上下限代入 $0$ 和 $\infty$，上下限差出负号把分母负号抵消，得到 $\frac{1}{s - k}$。
    
2. **$t$ 的高次幂**：本质就是**分部积分反复降阶**——每降一次 $t$ 的次数，就乘上当前指数并除以 $s$，所以分子出现 $n!$，分母变成 $s^{n+1}$。
    
3. **带 $e^{-at}$ 乘积的项**：不必每次重算分部积分，**指数合并后直接把 $s$ 替换成 $s + a$** 即可（$\mathcal{L}\{e^{-at}f(t)\} = F(s+a)$）。
