| **字段名称**                                           | **位宽 / 长度**        | **完整注释与说明**                                                                                                                                                                                                                                                     |
| -------------------------------------------------- | ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **版本**（Version）                                    | 4 bit              | IP 协议版本号，IPv4 固定为 `4`（`0100`）；IPv6 为 `6`。                                                                                                                                                                                                                       |
| **首部长度**（IHL, Internet Header Length）              | 4 bit              | 以 **32 位字（4 字节）** 为单位表示 IP 头部长度。无选项时为 `5`（`5 × 4 = 20` 字节），最大值为 `15`（`15 × 4 = 60` 字节）；用于定位传输层报文起始位置。                                                                                                                                                           |
| **区分服务**（DSCP, Differentiated Services Code Point） | 6 bit              | 原服务类型（ToS）的高 6 位，用于 QoS 流量分类与优先级标记。                                                                                                                                                                                                                             |
| **显式拥塞通知**（ECN, Explicit Congestion Notification）  | 2 bit              | 原 ToS 的低 2 位，配合支持 ECN 的路由器和终端，在不丢包的情况下通告网络拥塞状态。                                                                                                                                                                                                                 |
| **总长度**（Total Length）                              | 16 bit（2 字节）       | **IP 头部 + IP 数据载荷（如 TCP/UDP 报文）** 的总字节数。最小为 `20`（仅头部），理论最大为 `65535` 字节；通过“总长度 - 首部长度”可算出上层数据长度。                                                                                                                                                                 |
| ==🔴**标识**（Identification）==                       | ==🔴16 bit（2 字节）== | ==🔴发送端为同一份原始 IP 数据报分配的唯一编号；当该包被**分片**时，所有分片复制相同的 Identification，供接收端重组识别。==                                                                                                                                                                                    |
| **标志位**（Flags）                                     | 3 bit              | 分片控制位：<br><br>  <br><br>• **Bit 0（保留位）**：必须为 `0`。<br><br>  <br><br>• **DF（Don't Fragment, Bit 1）**：`1` 表示禁止路由器分片（超过 MTU 时丢弃并返回 ICMP "Fragmentation Needed"）；`0` 表示允许分片。<br><br>  <br><br>• **MF（More Fragments, Bit 2）**：`1` 表示后面还有更多分片；`0` 表示这是最后一个分片（或未发生分片）。 |
| **片偏移**（Fragment Offset）                           | 13 bit             | 当前分片的数据载荷相对于原始未分片数据起点的偏移量，以 **8 字节** 为单位（即实际字节偏移 = `Fragment Offset × 8`）。首个分片偏移为 `0`。                                                                                                                                                                          |
| **生存时间**（TTL, Time to Live）                        | 8 bit（1 字节）        | 报文在网络中可经过的最大**跳数**（每经过一个三层转发路由器通常减 `1`）。减为 `0` 时路由器丢弃该包并回传 **ICMP Time Exceeded**，防止路由环路导致无限转发。                                                                                                                                                                 |
| **协议**（Protocol）                                   | 8 bit（1 字节）        | 指明封装在 IP 数据载荷中的上层协议类型，常见取值：<br><br>  <br><br>• `1`：ICMP<br><br>  <br><br>• `6`：TCP<br><br>  <br><br>• `17`：UDP<br><br>  <br><br>• `41`：IPv6 封装                                                                                                                  |
| **首部校验和**（Header Checksum）                         | 16 bit（2 字节）       | **仅校验 IPv4 头部**（不含数据载荷），采用 16 位反码求和。因为每跳 TTL 和部分字段会变化，所以每经过一个路由器都需要重新计算/更新首部校验和（TCP/UDP 校验和则由端到端计算）。                                                                                                                                                            |
| **源 IP 地址**（Source IP Address）                     | 32 bit（4 字节）       | 发送方网络接口的 IPv4 地址。                                                                                                                                                                                                                                               |
| **目的 IP 地址**（Destination IP Address）               | 32 bit（4 字节）       | 接收方网络接口的 IPv4 地址（若经过 NAT，中间网关会改写源/目的 IP 及对应传输层校验和）。                                                                                                                                                                                                             |
| **选项**（Options）                                    | 0 ~ 40 字节          | 少见的可选字段（如严格/松散源路由、记录路由、时间戳），长度需补齐为 4 字节的整数倍。                                                                                                                                                                                                                    |
